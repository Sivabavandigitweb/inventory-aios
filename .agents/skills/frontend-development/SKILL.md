# Frontend development

Use this skill for Inventory AIOS frontend implementation and review.

- Use React, TypeScript, and Vite with reusable components, typed data flow, forms, and API integration.
- Support responsive desktop, tablet, and mobile layouts; preserve usable states for loading, empty, error, and permission-limited views.
- Treat accessibility as a functional requirement: semantic structure, keyboard operation, labels, focus management, and appropriate status feedback.
- Keep API boundaries explicit and handle validation and server errors without exposing sensitive details.
- Prefer focused component and interaction tests; use Vitest where frontend behavior needs verification.
- Do not infer business rules or authorization from the UI; enforce those rules through the backend and reflect confirmed requirements in the interface.
