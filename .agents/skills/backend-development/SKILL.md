# Backend development

Use this skill for Inventory AIOS backend implementation and review.

- Use FastAPI and Pydantic with versioned API routes and clear request/response schemas.
- Apply authentication and role-based authorization at protected service boundaries; never rely on frontend checks alone.
- Separate routing, validation, service logic, and persistence concerns so business rules are testable.
- Validate inputs and return deliberate, safe errors that do not leak credentials, internals, or sensitive records.
- Make transaction boundaries and failure behavior explicit, especially for inventory lifecycle operations.
- Preserve confirmed requirements and identify unresolved authorization or policy decisions instead of inventing them.
