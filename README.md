# Inventory AIOS

Inventory AIOS is an inventory management project intended to provide a modern web application for managing inventory data and related workflows.

## Technology stack

- Frontend: React, TypeScript, and Vite
- Backend: FastAPI and Python
- Database: PostgreSQL
- Persistence and migrations: SQLAlchemy and Alembic
- AI integration: Grok API

The project structure is being established first. Application code and dependencies will be added in later steps.
